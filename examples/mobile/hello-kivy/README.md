# Hello Kivy — Kivy UI smoke test for kivyforge 3.0

Minimal Kivy app (`Label` with "Hello Kivy") using the official **python.org**
iOS `Python.xcframework` preview (**3.15.0b4**).

Kivy **3.0** iOS wheels are not on PyPI yet for cp315. This example resolves
them from [`kivy-mobile-wheels`](https://github.com/ElliotGarbus/kivy-mobile-wheels),
a personally-owned bridge repo that builds them in CI and serves them over a
PEP 503 index on GitHub Pages — `kivyforge lock` pins them by `url` + SHA-256,
exactly like a PyPI package, via `[tool.kivy.ios].extra_index_urls`. (See
that repo's own recipes if you need to build a Kivy 3.0 iOS wheel yourself;
this example just consumes the published ones.)

## Prerequisites

- macOS with Xcode (same as [hello-world](../hello-world/README.md))
- Metal Toolchain installed (`xcodebuild -downloadComponent MetalToolchain` if
  `xcrun -find metal` fails — required for Kivy's SDL3 iOS deps)
- kivyforge 3.0 installed from this repo (`pip install -e ".[dev]"`)
- Network access to `elliotgarbus.github.io` and `github.com` the first time
  you lock, to resolve and download the wheels

## Lock, build, run

```bash
cd examples/mobile/hello-kivy
kivyforge lock --update
kivyforge build --simulator
kivyforge run --simulator
```

`[tool.kivy.ios].extra_index_urls` tells `kivyforge lock` to resolve Kivy from
the `kivy-mobile-wheels` index alongside PyPI; pure-Python deps (e.g.
`more-itertools`) still come from PyPI directly. The lockfile records `url` +
SHA-256 for each wheel slice.

## Files

| Path | Purpose |
|------|---------|
| `pyproject.toml` | App config + `extra_index_urls` pointing at the `kivy-mobile-wheels` index |
| `pylock.ios.toml` | Generated by `kivyforge lock`. **Intentionally committed** — it's evidence, not just build input: it records the exact wheel hashes that passed the on-device simulator gate below, so re-running it later validates the same binaries rather than silently re-resolving new ones from the bridge index. Every other example's lock is gitignored. See "Example-repo lock policy" in [`03-lockfile-concept.md`](../../../docs/design/common/03-lockfile-concept.md). |
| `src/main.py` | Kivy `App` with a single `Label` |
