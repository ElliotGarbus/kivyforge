# SVG Explorer — interactive Kivy SVG demo for kivyforge 3.0

A richer Kivy app than [hello-kivy](../hello-kivy/README.md). It renders vector
drawings with Kivy's SVG engine and lets you manipulate them with multitouch:

| Gesture / control | Action |
|-------------------|--------|
| drag              | pan the drawing |
| pinch (2 fingers) | zoom |
| twist (2 fingers) | rotate |
| **Prev / Next**   | cycle through the bundled SVG drawings |
| **Reset**         | fit the current drawing back to the view |
| **BG**            | toggle the background (dark / light) |

The drawings live in [`src/assets`](src/assets/) (`star.svg`, `heart.svg`, and a
gradient-filled `hexagon.svg`) and are loaded by path at runtime, so they ride
into the app bundle through the generated `app/` source link.

Uses the official **python.org** iOS `Python.xcframework` preview (**3.15.0b4**)
and, like hello-kivy, resolves its `cp315` Kivy iOS wheel from the
[`kivy-mobile-wheels`](https://github.com/ElliotGarbus/kivy-mobile-wheels)
index, pinned by `kivyforge lock`.

## Prerequisites

- macOS with Xcode (same as [hello-world](../hello-world/README.md)).
- kivyforge 3.0 installed from this repo (`pip install -e ".[dev]"`).
- Network access to `elliotgarbus.github.io` and `github.com` the first time
  you lock, to resolve and download the Kivy wheel.

If the wheel can't be resolved, `kivyforge doctor`'s "Required hosts
reachable" check reports which host is unreachable before `kivyforge lock`
hits a cryptic pip error.

## Lock, build, run

```bash
cd examples/mobile/svg-explorer
kivyforge lock --update
kivyforge build --simulator
kivyforge run --simulator
```

`[tool.kivy.ios].extra_index_urls` tells `kivyforge lock` to resolve Kivy from
the `kivy-mobile-wheels` index; the lockfile records `url` + SHA-256 for each
wheel slice.

You can also open the project in Xcode and press Run:

```bash
kivyforge open
```

## Run on desktop first (optional)

It's a standard Kivy app, so you can sanity-check the UI on your Mac before
bundling (in a Python env that has desktop Kivy installed):

```bash
python examples/mobile/svg-explorer/src/main.py
```

## Files

| Path | Purpose |
|------|---------|
| `pyproject.toml` | App config + `extra_index_urls` pointing at the `kivy-mobile-wheels` index |
| `src/main.py` | Interactive `Scatter`-based SVG viewer |
| `src/assets/*.svg` | The vector drawings rendered by the app |
| `pylock.ios.toml` | Generated by `kivyforge lock`; gitignored (regenerate with `kivyforge lock --update`) |
| `svg-explorer-ios/` | Generated Xcode tree (gitignored; recreated by `kivyforge build`) |
